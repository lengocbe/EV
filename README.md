# Ghép Từ Vựng Android

Game ghép thẻ học tiếng Anh - tiếng Việt, chạy hoàn toàn trên điện thoại không cần Internet.

## Chức năng

- Mỗi lượt xáo trộn tối đa 10 cặp thẻ; cột trái là tiếng Việt, cột phải là tiếng Anh.
- Chọn đúng hai thẻ sẽ hiện xanh rồi biến mất; chọn sai chớp đỏ rồi trở lại bình thường.
- Nhập thêm cặp từ trực tiếp trong app.
- Import `.csv` hoặc `.xlsx`; cột A là `English`, cột B là `Vietnamese`. Dòng tiêu đề là tùy chọn.
- Lưu dữ liệu từ vựng cục bộ trên thiết bị.

## Android Studio

Mở đúng thư mục project bằng Android Studio, chờ Gradle Sync, sau đó bấm Run. Project dùng Android SDK 35 và Java 17.
